# Spateo 全技术自动读取测试报告（2026-09-20）

## 结论与适用范围

新增无评分入口支持的 **11 类技术／表示**均已完成格式契约测试。该数字将 Visium、HD bin 和 HD cellseg 分开计数，并将 Stereo-seq/BGI 合并为同一读取类别；不是 11 个独立生物学技术的统计样本。

- 合成格式测试：**10 轮 × 11 类 × 5 种场景 = 550 个测试案例**；每例重复读取 3 次，共 **1,650 次调用**。
- 有效案例识别：**220/220 = 100%**；核心表达、ID、基因名和坐标完整一致：**220/220 = 100%**。
- 非法案例拒绝：**330/330 = 100%**；错误输入被读为成功：**0/330**。
- 重复结果一致：**550/550**；这 3 次重复仅用于稳定性检查，不把样本数放大为 1,650。
- 真实来源／已有本地数据：**7 类、10 份完整核心或明确派生的测试输入**，每份重复 3 次；最终 **30/30** 次读取与全量内容对照通过。
- 扩展后 IO 与预处理回归：**81 项通过**，`make check` 通过。

**这里的 100% 是指定测试集上的结果，不是所有真实数据的总体识别准确率。** 合成数据的格式是人工构造的，正常／打乱顺序的案例共用基础表达数据；真实输入包含子集与可能相关来源，不能当作独立随机抽样。尚未完成全部 11 类平台的完整真实数据验证。

## 1. 轮次、输入和判定标准

每轮使用一个固定随机种子，种子为 20260921–20260930。每个格式生成 8–29 个观察、5–19 个基因的稀疏计数与已知坐标，然后用相应格式独立写入文件。输入值和预期结果不由被测 reader 生成。

每轮每类包含五种场景：

1. 正常输入：平台、表达、ID、基因名、坐标全部正确。
2. 元数据顺序打乱：必须通过 ID 关联恢复原矩阵观察顺序；BGI 改变分子行顺序。
3. 非法表达：表达中加入非有限值，必须拒绝。
4. 非法坐标：坐标中加入非有限值或无效几何，必须拒绝。
5. 缺失核心内容：删除坐标文件；BGI 删除必须的 x 列，必须拒绝。

识别正确率的分母为 **220 个有效案例**。成功要求集合 `ok`、唯一对象、技术正确；内容正确还要求矩阵、观察顺序、基因名和全部坐标与独立预期精确一致。错误输入必须集合 `failed` 且不产生任何 AnnData，才计为正确拒绝。没有使用“换个平台读成功”作为成功标准。

每类 20 个有效案例、30 个非法案例；对每个案例重复调用 3 次。稳定性比较状态、输出技术、内容检查与条目状态；时间差不作为不稳定。

## 4. 保留的失败、限制和修复过程

### 格式兼容问题

扩展验证前，真实 seqFISH 的 `label` 列无法被识别为细胞 ID；真实 STARmap 空间表的首行 `NAME=TYPE`、坐标字段 `numeric` 被当作观察。已补充技术限定的 ID 别名和严格声明行解析，并增加 4 个回归测试。无效 TYPE 声明仍拒绝；不采用任意跳行或填零。

最初交付候选的相关回归为 77 项通过，补充后为 81 项通过。探索性的文件检查用于发现问题，不和正式基准案例混在一起计算准确率。

### 真实内容核验器的精度问题

真实文件正式比对执行了 **两批，每批 10 份 × 3 次 = 30 次**，共 60 次调用；独立输入仍为 10 份。

- 初批：10/10 份均能正确识别并读取；内容精确比较为 8/10 份、24/30 次通过。两份 Xenium 的矩阵和 ID 一致，但坐标逐位比较失败。
- 原因：基准脚本使用 pandas 默认浮点解析，与按源字符串精确转换的结果存在最大约 `4.55e-13` 和 `1.14e-13` 的差异。
- 修正：独立源数据解析改为 `float_precision="round_trip"`。**没有放宽比较误差，也没有修改 reader 的坐标值。**
- 终批：10/10 份、30/30 次全部精确一致。初批失败记录与终批记录同时保存。

### 未被子集成功掩盖的原始目录状态

- 原始 HD 目录同时有 H5 和 MEX；过滤矩阵的多编码保持 `unresolved`。测试显式创建单一 H5 子集后能读取，不代表原目录已消除歧义。完整 raw 矩阵的元信息估计约 6.75 GB，未在默认预算下完整载入。
- 本地 Slide-seq 目录只有 bead 坐标、缺少表达文件，报告 `failed`，不补造矩阵。
- 本地另一份 seqFISH cortex 导出布局不在当前支持契约内，报告 `failed`；不能因为同属 seqFISH 就声称所有历史导出均支持。
- 大型 MERFISH／STARmap／seqFISH／HD／BGI 本次采用显式子集；完整大文件的内存表现和吞吐没有得到这个基准的证明。

## 5. 时间统计

下列耗时包含读取与内容断言，使用当前本机环境；合成数据很小、重复会受到操作系统缓存影响。它们是复现记录，不是大型真实输入的性能承诺。

- 合成调用中位数：4.88 ms；P95：8.22 ms。

```bash
python scripts/benchmark_automatic_spatial_reading.py --rounds 10 --repeats 3 --output /path/to/synthetic_report

python scripts/benchmark_spatial_local_data.py \
  --primary-root /path/to/0.io \
  --secondary-root /path/to/dataset \
  --visium-root /path/to/V1_Adult_Mouse_Brain \
  --output /path/to/real_report --repeats 3

SPATEO_VISIUM_DATA=/path/to/V1_Adult_Mouse_Brain python -m pytest -q tests/io tests/preprocessing
```
